# 🤖 AI Assistant

A simple conversational AI application built using Python, Streamlit and Ollama.

### Features
- Interactive AI chat interface
- LLM integration using Ollama
- System prompts to define AI behaviour
- Real-time AI responses

### Tech Stack
Python | Streamlit | Ollama | Llama 3.2

### Run the Application

```bash
streamlit run app.py
```

Ensure Ollama is running and Llama 3.2 is installed.
