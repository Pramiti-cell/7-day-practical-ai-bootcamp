# 🧠 Prompt Engineering Playground

An interactive application to experiment with prompt engineering techniques and compare LLM responses.

### Features
- Weak vs Strong Prompt Comparison
- Role-Based Prompting
- Creative, Balanced and Precise Response Styles
- Structured JSON Prompting
- Save and Reuse Prompt Templates
- Ollama LLM Integration

### Tech Stack
Python | Streamlit | Ollama | Llama 3.2 | JSON

### Run the Application

```bash
streamlit run app.py
```

Ensure Ollama is running and Llama 3.2 is installed.
